# External mounts and enclosure (deferred)

Mechanical work is not part of active V1. Historical Tickets 23 and 25 proposed
a removable camera mount/enclosure after camera,
lighting and target-meter measurements are known. Do not obstruct authorised
meter access or require opening/modifying the installed meter.

Keep editable components under `parts/<component>/`. Future handoffs live in
`out/<part>/`: printer files, checks, three distinct PNG views and a short
README with rebuild instructions and qualification limits. Reference-only
models go in `out/references/<model>/`, marked "do not print".

Choose practical CAD tooling; Python is optional. Do not copy Switch geometry
as if it fits this product. No CAD or print outputs exist yet.
